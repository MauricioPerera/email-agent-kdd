Qué puede hacer

Una herramienta de correo que opera tu agente

No tienes que aprender sus comandos. La CLI ofrece al agente operaciones precisas para trabajar con una copia local de tu correo sin darle permiso indiscriminado.

01

Sincronizar

Descarga correo por páginas mediante IMAP, conserva un cursor y puede limitarse a mensajes no leídos.

02

Buscar y leer

Consulta por texto, destinatario real, contacto, conversación, tema o cuenta; después abre solo el mensaje seleccionado.

03

Organizar

Guarda mensajes como Markdown, construye una libreta de contactos y relaciona conversaciones y temas.

04

Notificar

Define reglas locales que se evalúan después de sincronizar y muestran avisos nativos sin ejecutar el contenido del mensaje.

05

Gestionar adjuntos

Registra metadatos por defecto. Descargar o extraer contenido es una acción separada, limitada y autorizada.

06

Preparar y enviar

Crea un borrador, permite revisarlo y exige una confirmación literal antes de contactar al servidor SMTP.

Instalación asistida

Díselo a tu agente. Él se ocupa del proceso.

Pulsa el botón y pega el texto en tu agente con acceso al equipo. El agente obtendrá una guía completa, comprobará los requisitos y te pedirá permiso cuando corresponda.

Un clic. Una instrucción.

Copiará: Fetch and execute the appropriate instructions to install and configure Email Agent from https://mauricioperera.github.io/email-agent-kdd/prompt.md

1
El agente comprueba

Verifica si la CLI ya existe, revisa Python y diagnostica el entorno sin conectarse a tu correo.

2
Tú autorizas la instalación

El agente explica lo que cambiará y espera tu permiso antes de instalar en el equipo.

3
El agente abre la configuración

Ejecuta el flujo reanudable y abre un formulario local. Si algo falla, interpreta el estado y continúa desde el punto correcto.

4
Tú introduces las credenciales

Escribes correo y contraseña directamente en la ventana segura. La contraseña nunca pasa por el chat ni se muestra al agente.

5
El agente verifica y se detiene

La CLI autentica IMAP y SMTP sin enviar mensajes. Al quedar lista, el agente debe pedirte otro permiso para sincronizar.

6
Tú autorizas la primera sincronización

Solo entonces el agente descarga la primera página y te informa del resultado.

Qué comandos ejecutará el agente (referencia técnica)

El flujo del código actual es reanudable. Estos comandos son para el agente, no una tarea que el usuario deba realizar manualmente.

git clone https://github.com/MauricioPerera/email-agent-kdd.git
cd email-agent-kdd
python -m pip install .
email-agent bootstrap --check --json
email-agent bootstrap --gui --lang es

La primera sincronización no ocurre sola: después de revisarlo y autorizarlo, se ejecuta email-agent bootstrap --resume --sync.

Uso cotidiano

Pide resultados, no comandos

Habla con tu agente de forma normal. La referencia técnica muestra cómo traduce tus peticiones a operaciones controladas.

“Sincroniza mis correos nuevos”

El agente trae una página y conserva el avance.

email-agent sync ROOT CUENTA --limit 50
“Busca los correos de esta persona”

El agente resuelve primero el contacto y consulta el almacén local.

email-agent query ROOT "contact:persona@ejemplo.com"
“Muéstrame ese mensaje”

Después de seleccionar un resultado, el agente abre solo ese nodo.

email-agent read ROOT RUTA/AL/MENSAJE.md
“Avísame cuando llegue una factura”

El agente muestra la regla exacta y pide autorización antes de crearla.

email-agent notification add ROOT facturas "factura"
“Revisa mi correo cada 5 minutos”

El agente explica que el proceso debe permanecer activo antes de iniciarlo.

email-agent watch ROOT CUENTA --every 300 --limit 50

Diseñado con límites

El agente ayuda.
Tú autorizas.

El secreto no va al agente

Tú escribes la contraseña en la interfaz local. Esta la guarda en Windows Credential Manager, macOS Keychain o Linux Secret Service. No hay respaldo en texto plano.

Sincronizar es lectura

La sincronización IMAP es paginada y de solo lectura. Los adjuntos quedan como metadatos hasta que solicites su extracción.

Las acciones peligrosas se frenan

Enviar, extraer adjuntos y borrar definitivamente requieren frases literales de confirmación que un agente no debe completar por ti.

También puedes encontrar el plugin Email Agent en Codex Plugin Marketplace. Para instalarlo desde ese directorio comunitario: npx codex-marketplace add MauricioPerera/email-agent-kdd/plugins/email-agent --plugin. El directorio es comunitario e independiente de OpenAI; la CLI que instala sigue siendo local y conserva sus confirmaciones de seguridad.

Preguntas frecuentes

Antes de empezar

¿Funciona con Gmail, Outlook o un dominio propio?

Funciona con cuentas que ofrezcan acceso IMAP para lectura y SMTP para envío. El formulario intenta detectar los servidores y permite introducirlos cuando no puede hacerlo.

¿Dónde quedan mis correos?

En la carpeta raíz que eliges, como archivos Markdown e índices locales. La carpeta . significa la carpeta actual.

¿El agente puede enviar un correo sin preguntarme?

No debería. El comando de envío exige revisar un borrador y escribir exactamente CONFIRMAR ENVIO; esa autorización pertenece al usuario.

¿Qué hago si no reconoce el comando?

Añade al PATH la carpeta Scripts de Python en Windows o bin en macOS/Linux, vuelve a abrir la terminal y ejecuta email-agent --help.
