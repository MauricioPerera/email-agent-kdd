Tu correo se convierte en conocimiento útil, sin salir de tu equipo.

Email Agent sincroniza tus mensajes en un almacén Markdown local para que tú —o un agente que te asista— pueda buscar, leer, organizar y preparar acciones con controles explícitos.

Qué puede hacer

Una interfaz segura entre tu correo y un agente

No reemplaza a tu proveedor de correo. Crea una copia local consultable y ofrece comandos precisos para actuar sin dar acceso indiscriminado.

01

Sincronizar

Descarga correo por páginas mediante IMAP, conserva un cursor y puede limitarse a mensajes no leídos.

02

Buscar y leer

Consulta por texto, destinatario real, contacto, conversación, tema o cuenta; después abre solo el mensaje seleccionado.

03

Organizar

Guarda mensajes como Markdown, construye una libreta de contactos y relaciona conversaciones y temas.

04

Notificar

Define reglas locales que se evalúan después de sincronizar y muestran avisos nativos sin ejecutar el contenido del mensaje.

05

Gestionar adjuntos

Registra metadatos por defecto. Descargar o extraer contenido es una acción separada, limitada y autorizada.

06

Preparar y enviar

Crea un borrador, permite revisarlo y exige una confirmación literal antes de contactar al servidor SMTP.

Instalación sencilla

De cero a tu primera cuenta

Necesitas Python 3.10 o superior. El instalador estable descarga artefactos de la versión v0.2.0, verifica su integridad SHA-256 y comprueba el comando al terminar.

  1. Descarga el instalador

    Abre PowerShell, pega estas líneas y presiona Enter.

    $archivo = "$env:TEMP\email-agent-install.ps1"
Invoke-WebRequest https://raw.githubusercontent.com/MauricioPerera/email-agent-kdd/main/installers/install.ps1 -OutFile $archivo
powershell -File $archivo
  2. Comprueba la instalación
    email-agent --help
  3. Abre el formulario de configuración
    email-agent account setup-gui .

    La prueba inicia sesión en IMAP y SMTP, pero no envía ningún mensaje.

  1. Descarga y ejecuta el instalador

    Abre Terminal, pega estas líneas y presiona Enter.

    curl -fsSL https://raw.githubusercontent.com/MauricioPerera/email-agent-kdd/main/installers/install.sh -o /tmp/email-agent-install.sh
sh /tmp/email-agent-install.sh
  2. Comprueba la instalación
    email-agent --help
  3. Abre el formulario de configuración
    email-agent account setup-gui .

    En Linux, el formulario requiere una sesión de escritorio con Secret Service/libsecret disponible.

Instalar el código actual del repositorio (avanzado)

Este camino incluye el flujo reanudable bootstrap del código actual. Requiere Git.

git clone https://github.com/MauricioPerera/email-agent-kdd.git
cd email-agent-kdd
python -m pip install .
email-agent bootstrap --check --json
email-agent bootstrap --gui --lang es

La primera sincronización no ocurre sola: después de revisarlo y autorizarlo, se ejecuta email-agent bootstrap --resume --sync.

Uso cotidiano

Comandos pequeños, intención explícita

Sustituye CUENTA por el identificador que muestra la configuración.

Sincronizar

Trae hasta 50 mensajes y conserva el avance.

email-agent sync . CUENTA --limit 50
Consultar

Busca en el almacén local, sin conectarse al buzón.

email-agent query . "contact:persona@ejemplo.com"
Leer

Abre el contenido de un resultado concreto.

email-agent read . RUTA/AL/MENSAJE.md
Contactos

Encuentra candidatos sin modificar la libreta.

email-agent contact find . "Nombre"
Revisar cada 5 minutos

Funciona mientras el proceso permanezca abierto.

email-agent watch . CUENTA --every 300 --limit 50

Diseñado con límites

El agente ayuda.
Tú autorizas.

El secreto no va al agente

La interfaz gráfica guarda la contraseña en Windows Credential Manager, macOS Keychain o Linux Secret Service. No hay respaldo en texto plano.

Sincronizar es lectura

La sincronización IMAP es paginada y de solo lectura. Los adjuntos quedan como metadatos hasta que solicites su extracción.

Las acciones peligrosas se frenan

Enviar, extraer adjuntos y borrar definitivamente requieren frases literales de confirmación que un agente no debe completar por ti.

Preguntas frecuentes

Antes de empezar

¿Funciona con Gmail, Outlook o un dominio propio?

Funciona con cuentas que ofrezcan acceso IMAP para lectura y SMTP para envío. El formulario intenta detectar los servidores y permite introducirlos cuando no puede hacerlo.

¿Dónde quedan mis correos?

En la carpeta raíz que eliges, como archivos Markdown e índices locales. La carpeta . significa la carpeta actual.

¿El agente puede enviar un correo sin preguntarme?

No debería. El comando de envío exige revisar un borrador y escribir exactamente CONFIRMAR ENVIO; esa autorización pertenece al usuario.

¿Qué hago si no reconoce el comando?

Añade al PATH la carpeta Scripts de Python en Windows o bin en macOS/Linux, vuelve a abrir la terminal y ejecuta email-agent --help.
