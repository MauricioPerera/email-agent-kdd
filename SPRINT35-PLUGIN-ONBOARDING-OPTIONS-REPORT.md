# Sprint 35 — Contrato de opciones del plugin

## Objetivo

Evitar que la documentación del plugin omita opciones necesarias del
onboarding.

## Resultado

La prueba congelada exige que la skill documente `onboard ROOT`, `--gui`,
`--terminal` y `--lang es|en|pt`. Así un agente puede seleccionar el flujo y
el idioma sin deducir sintaxis no documentada.

## Verificación

La batería completa valida el manifiesto, la skill y los instaladores.
